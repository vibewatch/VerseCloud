# 诗云 · Verse Cloud

诗云是一座可运行的中国古典诗词空间：从先秦到清代，在 WebGL 真实地形、时代坐标和程序化音景中阅读 313 首诗词，并沿 84 位诗人的生平行迹理解作品与地理的关系。其中 194 首覆盖当前统编小学、初中古典诗词篇目（小学 110 首、初中 84 首）；文言散文和 1912 年后的现代作品不纳入这条古典诗史时间线。作品按文学时期与教材范围筛选，地点按“创作地、作品场景、行旅节点、诗中提及、人物关联地”严格区分，并公开显示证据与置信度。

## 本地运行

需要 Node.js 22 或更高版本，以及本机 Chrome（端到端测试使用真实 WebGL）。

```bash
npm ci
npm run dev
```

完整质量门禁：

```bash
npm run typecheck
npm test
npm run verify:corpus
npm run test:e2e
npm run build
```

端到端测试由 Playwright 自动启动 Vite，覆盖桌面、390px 移动端、地图交互、音频节点上限、全部文学时期、诗库搜索和 WebGL 上下文稳定性。

## 产品体验

- 顶部可横向滚动的 11 时期导航；当前时期、作品年份和年号同步更新。
- 诗库分“诗词”“人物”两页：313 首作品可按诗题、作者、地点、年号和“小学/初中”查找；人物页以一幅海岸线速写勾出每位诗人的行迹，点选即进入其生平。
- 可俯仰、旋转、缩放的 MapLibre GL 地形地图，视野与请求范围限制在中国及周边。
- 作品地点使用 WebGL 抽象诗签；同址多诗合并为带数目印记的诗簇，远景下邻近地点聚合为墨点，拉近后逐级展开，不再以错层堆叠。
- 选诗后镜头平滑聚焦，全文以古籍式竖排呈现；卷面按可用宽度合并和平衡相邻短句，再按最长列和视口计算字号。长词与《木兰诗》一类长篇在移动端也不会挤出卷面或视口。
- 左侧“时 · 人 · 地”卷册把一首诗放回三重坐标：时期年轴上标出诗人一生与作品落点；人物行注明作诗时年岁、籍贯与离乡里程及交游；地点行列出同一地点跨朝代的其他作品。
- “行迹”模式以玉色虚线串起诗人一生的驻留地，编号站点与籍贯朱印落在地图上，诗签折叠为小签、其余诗光淡出；卷册同步列出每一站的年份、事件与当地作品，可逐站阅读或经“交游”跳到同时代诗人的行迹。
- 作品之间以 WebGL 渐变墨线标示行旅；滚轮拉近时当前诗签沿固定轨迹向视野中心吸附。
- 春、夏、秋、冬四套场景配色，以及花影、轻舟、月火、烟渚、层楼、云鹤、瀑布、朝雨八类轻量意象动画。
- 基于 Tone.js 的长安、江南、西域三层实时环境音景；八类视觉意象分别绑定稳定的调式、速度、节奏和空间效果，并以双音轨交叉淡化。
- 音频引擎复用固定声部；静音会暂停 Transport 和 AudioContext，避免长时间使用后音频节点持续增长。
- 支持减少动态效果偏好、键盘操作、清晰焦点态、静音降级和地图渲染失败回退。
- 桌面侧栏与移动端全屏诗库采用同一信息架构；所有控件均为定制组件，不依赖原生下拉菜单。

## 数据与考据边界

`src/data/poems.ts` 保留人工校订的核心展示语料；`src/data/schoolPoems.generated.ts` 是教材古诗词清单与全文，`src/data/schoolPoems.ts` 为它补齐可审计的地图与视觉元数据。每条发布记录都包含：

- 文本、作者、文学时期和约年；
- 经纬度、地点名与地点关系；
- `high`、`medium`、`low` 三级置信度；
- 地理判断说明、文本来源和视觉主题。

低置信度坐标只作为文化区域或人物活动的阅读锚点，不代表创作地。应用不会把作品场景、诗中提及地和人物关联地混作创作地。`src/data/poets.test.ts` 另行校验诗人档案：驻留站年份须在生卒之内并按时间排序、坐标在地图范围内、有档案诗人的作品年代落在其一生之内、交游对象必须同样建档。`src/data/poems.test.ts` 会验证时期覆盖、唯一 ID、文本完整性、坐标范围、证据、HTTPS 来源和年代边界。

教材范围以当前统编小学、初中语文古典诗词目录为边界：收录诗、词、曲和乐府，排除文言散文、蒙学韵文及辛亥以后现代诗词。`npm run verify:corpus` 会核对 194 首教材作品均已进入发布诗库；`npm run build-school-poems` 可从公开目录重新生成静态语料，生成结果仍需人工复核后提交。

`src/data/tangGeography.ts` 中的唐代道界和地名是艺术化阅读层，不主张复原某一具体年份。`src/data/mapSnapshots.ts` 保留文学时期元数据与唐代概念边界，当前地图不渲染任何朝代疆域填色、外边界或疆域外遮罩。

## 技术结构

```text
src/App.tsx                       时期导航、诗库、音景与应用状态
src/components/VerseScene.tsx    WebGL 地图、地点、路线与竖排诗签
src/components/SceneBoundary.tsx 地图错误回退
src/components/PoemFolio.tsx     时 · 人 · 地卷册与行迹站表
src/components/PoetRegister.tsx  诗库人物页与行迹速写
src/data/poems.ts                 核心校订诗词与发布合并
src/data/schoolPoems.generated.ts 194 首小学、初中教材古诗词
src/data/schoolPoems.ts           教材诗词的地图、年代与视觉元数据
src/data/expandedPoems.ts         教材以外的扩充诗词
src/data/poets.ts                 84 位诗人的生卒、籍贯、交游与 413 个生平驻留站
src/data/mapSnapshots.ts          11 个文学时期及时间范围
src/data/tangGeography.ts         唐代概念道界与古地名阅读层
src/lib/                          地理投影、同址分组、诗人行迹、路线与音景
tests/e2e/                        真实浏览器验收测试
```

地图组件与 Tone.js 均按需加载。MapLibre worker 使用显式生产资源 URL；画布像素比上限为 1.5，移动端限制瓦片缓存和历史标签数量。生产构建通过 `vite build` 输出静态资源；GitHub Actions 自动部署至 GitHub Pages 自定义域名 [versecloud.genisisiq.com](https://versecloud.genisisiq.com/)，并使用根路径加载静态资源。

- 地表晕渲：Natural Earth，经 OpenFreeMap 提供。

- 小学、初中教材篇目目录与公开古籍文本：[古文岛](https://www.gushiwen.cn/gushi/xiaoxue.aspx)，生成后固化在仓库并由完整性测试校验。
- 中文字体：朱雀仿宋（Zhuque Fangsong），依 SIL Open Font License 1.1 自托管。

地图右下角始终显示运行时数据署名。外部地图瓦片不可用时，诗库、文本与证据仍保留在静态应用中；音频授权失败时应用自动以静音模式继续。
